## 回归覆盖

- 点位：首个策略必经点不跳过，策略与实时点合并去重，已经过与未经过分别判定，保留普通/必经分类。OBS 解压后的点位及围栏 JSON 与提交包装字符串逐字相同。测试远离道路、空路网/空裁剪和断开的道路分量会报错。
- 预览与道路生成：使用同一组合点位、围栏、距离、有效时长、种子及路由参数。检查预览几何一致、最终采样经过每个点位。新增 180° 折返保持测试，防止平滑切角漏掉必经点。
- 统计：1/9/10/11/59/60/61/180/603 秒覆盖完整及不满十秒尾窗、分钟边界，检查步数与距离总和及终点累计值，分钟片段取整后的距离合计也守恒。两个生成器做多种子回归，并校验时间文本与累计时间一致。
- 单位与公里边界：1000 米、600 秒、1200 步得到 avgPace=10.00 分钟/公里、avgStride=83.33 厘米；2500 米拆成 1000+1000+500 米，圈时间和步数之和守恒；零步数的步幅输出 null，零距离不生成虚假圈；毫秒级尾圈舍入到同一秒时不凭空增加 1 秒，无法定义的配速/步频为 null。
- 轨迹偏移：经典与道路模式均测试额外异常位移控制、半径及速度上限。源码中移除数百米的随机异常位移；经典模式仍无建筑避让保证。
- 结果：模拟详情读取成功但未达标、判定字段缺失、详情读取失败、OBS 1/2 成功、前后两次结果不同。UI 分别显示记录提交、OBS、详情读取和服务端判定，后一次不继承前一次详情或原因。
- 围栏与日期：无围栏、无效围栏、真实区域 ID、多个区域未指定 ID；北京时间零点及跨日目录。没有使用旧围栏文件作为新任务元数据。
- UI：egui 无窗口帧通过实际界面函数发送滚轮与指针按下/释放事件，在 320×360、320×480、360×400、360×540、412×600、880×720 验证刷新、展开列表、滚动到查询并点击；320/360/412 宽度、400 高度验证账号表单展开、滚动到登录并点击空输入校验。桌面保留列表布局，另有既有布局测试回归。该测试不覆盖 Android 触摸分发、软键盘或系统生命周期。

## 修复时发现的问题

初轮测试指出旧的“全部十秒窗口均在有效配速内”断言与按真实累计轨迹统计不一致，已改为检验窗口守恒；路网样本中的离路点被移到道路节点，并另设不可达测试。随后新测试发现 180° 折返切角会裁去节点，修复平滑算法后通过，未放宽 40 米门限。扩展到 320×360 后，测试脚本也改为先滚动到列表开关再点击，而不要求所有控件同时处于首屏。原有时间测试还暴露出读取两次当前时间并要求毫秒完全相等的偶发失败，已改为以生成前后的时刻界定合法区间，未修改生产时间逻辑。以上失败均已在最终回归中消除。
